Análise do código 04 / 05

Herança & Polimorfismo

O que mudou na BubbleFilha para criar um comportamento visual diferente?

class BubbleFilha extends Bubble {
    constructor(x, y, tamanho, cor, velocidade) {
        super(x, y, tamanho, cor);

        this.velocidade = velocidade;
    }

    show() {
        stroke(this.cor);
        strokeWeight(4);
        noFill();

        rect(
            this.x,
            this.y,
            this.tamanho,
            this.tamanho
        );
    }

    move() {
        this.x += this.velocidade;
        this.y += this.velocidade;
    }
}

1. extends

Indica que BubbleFilha herda de Bubble.

2. super()

Chama o construtor da classe Bubble para inicializar x, y, tamanho e cor.

3. Polimorfismo

O método show() foi redefinido. A Bubble normal desenha uma elipse; a BubbleFilha desenha um retângulo.

Conclusão 05 / 05

O que aprendemos?

O projeto mostrou como os conceitos de POO aparecem funcionando juntos dentro de uma aplicação p5.js.

🧬

Herança

BubbleFilha aproveita a estrutura de Bubble por meio de extends.

🎨

Polimorfismo

BubbleFilha redefine show() para ter uma aparência diferente.

🔗

Associação

irAte(comida) usa o objeto comida como referência para movimentar a bolha.

Como a bolha encontra a comida?

Dentro de irAte(comida), a Bubble compara suas próprias coordenadas x e y com comida.x e comida.y. Se a bolha está antes da comida, aumenta sua coordenada; se está depois, diminui. Assim, ela vai se aproximando do alvo.

this.x ↔ comida.x this.y ↔ comida.y Movimento em direção ao alvo
